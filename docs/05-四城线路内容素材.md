## 一、深圳（一线数字之城 · 出发地）

### 标志景点

| 景点 | 一句话推荐 |
| --- | --- |
| 深圳湾公园 | 沿海骑行、看日落，城市与自然一步之遥 |
| 平安金融中心云际观光层 | 541 米高空俯瞰深圳，夜景绝佳 |
| 华侨城创意园（OCT-LOFT） | 文艺街区，展览、咖啡馆、独立书店 |
| 大鹏所城 + 较场尾 | 600 年古城 + 海边民宿，一日逃离 |
| 海上世界 | 蛇口滨海休闲区，明华轮地标 |
| 南头古城 | 城中村改造的文创街区，新潮小店 |

### 推荐线路

**一日线 · 城市微旅行**
深圳湾公园（骑行/看海）→ 华侨城创意园（午餐+逛展）→ 平安金融中心（日落+夜景）

**两日线 · 山海深圳**
Day1：大鹏所城（古城漫步）→ 较场尾（海边民宿/沙滩）
Day2：杨梅坑 + 鹿嘴山庄（海岸线徒步）→ 回市区

**AI 主题线 · 数字深圳（旅居/游学）**
腾讯/大疆/华强北主题游 → AI 企业参访 → 与深圳 AI 从业者线下交流局
> 可承接未来「企业游学团建」业务雏形。

## 二、杭州（江南数字之城 · 出发地）

### 标志景点

| 景点 | 一句话推荐 |
| --- | --- |
| 西湖 | 晴湖不如雨湖，环湖处处是景 |
| 灵隐寺 + 飞来峰 | 千年古刹，山林清净 |
| 西溪湿地 | 城市湿地，摇橹船慢游 |
| 龙井村 | 茶园漫步，喝一杯明前龙井 |
| 良渚古城遗址 | 五千年文明，博物馆震撼 |
| 小河直街 / 拱宸桥 | 京杭大运河边的老杭州 |

### 推荐线路

**一日线 · 西湖经典**
断桥残雪 → 白堤 → 孤山 → 苏堤 → 花港观鱼 → 雷峰塔（日落）

**两日线 · 禅意与湿地**
Day1：灵隐寺 + 飞来峰 → 龙井村（茶园+喝茶）
Day2：西溪湿地（摇橹船）→ 小河直街（老杭州街区）

**数字线 · 互联网之城**
阿里巴巴西溪园区/梦想小镇周边 → 未来科技城 → 与杭州互联网从业者交流局

## 三、昆明（春城 · 云南门户）

### 标志景点

| 景点 | 一句话推荐 |
| --- | --- |
| 滇池 + 海埂大坝 | 昆明之肺，冬季红嘴鸥漫天 |
| 石林 | 世界自然遗产，喀斯特奇观 |
| 翠湖公园 | 市区明珠，冬日海鸥、夏天荷花 |
| 云南民族村 | 26 个民族风情浓缩 |
| 官渡古镇 | 老昆明小吃与古塔 |
| 斗南花市 | 亚洲最大鲜花市场，鲜花论斤卖 |
| 昆明老街 + 翠湖周边 | 咖啡馆与老建筑散步 |

### 推荐线路

**一日线 · 春城初见**
翠湖公园 → 云南大学/昆明老街（午餐）→ 斗南花市（买花）→ 滇池海埂大坝（日落）

**两日线 · 石林奇观**
Day1：石林（世界自然遗产）→ 返程市区
Day2：云南民族村 + 官渡古镇（小吃）

**旅居线 · 昆明慢生活（3–5 天）**
翠湖周边咖啡馆巡礼 → 篆新农贸市场（本地菜市场美食）→ 西山龙门（俯瞰滇池）→ 斗南花市 → 温泉一日

## 四、大理（风花雪月 · 旅居圣地）

### 标志景点

| 景点 | 一句话推荐 |
| --- | --- |
| 洱海 | 环湖 130 公里，骑行/自驾皆风景 |
| 苍山 | 洗马潭索道、寂照庵多肉花园 |
| 大理古城 | 人民路、复兴路，白族建筑与酒吧 |
| 喜洲古镇 | 稻田、白族民居、喜洲粑粑 |
| 双廊 | 洱海东岸，看日落、网红拍照 |
| 沙溪古镇 | 茶马古道最后的古集市，安静治愈 |
| 才村 / 龙龛码头 | 洱海边看日出，人少景美 |
| 崇圣寺三塔 | 大理地标，苍山脚下的千年古塔 |

### 推荐线路

**一日线 · 古城与洱海**
大理古城（人民路逛吃）→ 龙龛码头（骑行/看海）→ 喜洲古镇（稻田+粑粑）→ 返回古城

**两日线 · 环洱海**
Day1：大理古城 → 才村/龙龛（日出）→ 喜洲（午餐）→ 双廊（住宿/日落）
Day2：双廊 → 挖色/小普陀 → 大理古城（晚餐）

**三日线 · 苍洱深度**
Day1：苍山（洗马潭索道 + 寂照庵）
Day2：环洱海东线（双廊 + 沿途村落）
Day3：沙溪古镇（一日往返，茶马古道慢时光）

**旅居周线 · 大理生活体验（7 天）**
Day1 古城安顿 → Day2 洱海西线骑行 → Day3 喜洲+周城（扎染体验）→ Day4 苍山徒步 → Day5 双廊/东岸 → Day6 沙溪 → Day7 自由活动/告别局
> 旅居线可叠加：AI 分享会 / 摄影跟拍 / 咖啡馆探店局（本地人带玩版）。
