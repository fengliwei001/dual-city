# 双城记 · 项目总览（工作名）

> 深圳教 AI × 云南带玩 —— 文旅 × AI 的双城技能交换与兴趣社交平台
> 正式名称待定（候选方向：AI城市链接 / AI文旅 / 双城联动）

## 一句话定位

让深圳/杭州的年轻人把 AI 技能带到云南，让昆明/大理的本地朋友带他们玩——
**用技能换风景，用交换交朋友**。这是一个「兴趣社区 + 技能交换 + 文旅推荐」的混合型产品。

## 核心逻辑

| 一侧 | 给什么 | 得到什么 |
| --- | --- | --- |
| 深圳/杭州侧（一线数字青年） | 教 AI、资源对接、职业交流 | 云南本地人带玩、真实旅居体验、交朋友 |
| 昆明/大理侧（本地年轻人） | 带玩、接站、吃喝、本地攻略 | 学 AI、职业视野、一线资源连接 |

## 四城联动

- **深圳** / **杭州** —— 供给侧：AI 技能、资源、一线视角
- **昆明** / **大理** —— 目的地侧：带玩、旅居、在地生活

## 定位主线（v1）

**双线并重**：首页分「先认识」和「先匹配」两个入口

- 🗣️ **先认识**（社区线）：先聊、先认识、先组局
- 🔗 **先匹配**（撮合线）：先发需求、先匹配、先成交

## 三大核心场景（一级菜单下二级菜单）

- **A. 深圳人想去云南有人带**
- **B. 云南本地人想学 AI**
- **C. 双方交朋友、建圈子**

## 交换形式（v1 支持）

- 一对一互换
- 一对多（教/带）
- 小团对小团
- （平台默认原则：先自由组局，不强制）

## 付费旅居服务（v1 开放，线下结算）

带玩服务费 / 陪游费 / 摄影费 / 包车费 —— 平台先只做展示与撮合，不抽成。

## 第一版功能范围

官网介绍页 + 表单/社群入口 + 用户资料卡 + 匹配系统（私信、活动报名列为二期）
