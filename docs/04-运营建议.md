## 2. 冷启动策略（0 → 100 人）

### 2.1 供给先行：先拉云南侧

> 双边平台冷启动最容易死在「需求多、供给少」。云南侧供给者（本地带玩人）是稀缺资源，必须先行。

**种子渠道**：
- 大理/昆明旅居社群（豆瓣小组、微信群、小红书旅居博主）
- 民宿主理人 / 咖啡馆主 / 手作店店主（他们既是带玩者，又天然想学 AI 做自媒体）
- 新大理人圈子（数字游民、离职去大理的人群）
- 本地文旅从业者（导游、旅拍师、包车师傅）

**供给激励（首批）**：
- 「首批 100 位在地带玩人」认证徽章（纯展示，无认证概念）
- 帮他们做一张好看的公开名片（资料卡 = 免费宣传位）
- 优先对接深圳 AI 教学资源
- 后续可接付费带玩单（带玩/陪游/摄影/包车）

### 2.2 需求侧：深圳/杭州 AI 社群

**种子渠道**：
- 深圳科技社群：AI 交流群、产品经理社群、开发者 Meetup
- 即刻 / 豆瓣（「想去云南」「大理旅居」话题）
- 朋友圈私域：先从自己身边 30 个 AI 从业者开始
- 杭州互联网社群（补充供给池）

**需求激励（首批）**：
- 前 50 名深圳侧报名者赠送「云南本地私藏攻略包」
- 优先匹配权

### 2.3 首批 100 人运营动作

1. 官方一对一邀请：每个种子用户私聊确认意向、拉群；
2. 拉群后做「破冰动作」：群内自我介绍模板（套用资料卡字段）；
3. 人工撮合 3–5 对「深圳教 AI ↔ 云南带玩」作为示范案例，沉淀为官网素材。

## 3. 社群运营（核心阵地：微信群）

### 3.1 群体系设计

| 群 | 定位 | 运营动作 |
| --- | --- | --- |
| 四城总群 | 全局公告 / 活动发布 | 少打扰，仅重要信息 |
| 深圳群 | 深圳侧交流 / 组局 | 周话题、AI 小课通知 |
| 云南群 | 昆明/大理在地交流 | 本地攻略、带玩供给展示 |
| 主题群（按需） | 摄影搭子 / 咖啡搭子 / AI 学习群 | 群内自发为主 |

### 3.2 群规（模板）

1. 进群改昵称：城市-昵称-想交换什么（如「深圳-阿哲-教AI/想去大理」）；
2. 自我介绍用资料卡模板（发到群公告）；
3. 交换对等、尊重为先；禁止纯广告；
4. 线下见面安全提示：公共场所、报备行程；
5. 有纠纷找群主，平台规则兜底。

### 3.3 周运营节奏（模板）

| 日期 | 动作 |
| --- | --- |
| 周一 | 本周组局预告 / 需求墙精选 |
| 周三 | AI 小知识分享（深圳侧轮值） |
| 周五 | 云南本地攻略分享（云南侧轮值） |
| 周末 | 线上破冰局 / 线下见面局（试点） |

### 3.4 群内机器人（可选，V1.5）

- 报名表单自动汇总
- 需求墙自动同步
- 组局接龙

## 4. 内容运营（种草 + 信任）

### 4.1 小红书（主种草阵地）

**选题方向**：
- 大理带玩攻略（本地人视角）
- 深圳 AI 从业者旅居云南 vlog
- 「技能换风景」真实案例
- 四城线路推荐

**打法**：
- 每周 3–5 篇；图文为主；
- 统一话题：#大理带玩 #技能换风景 #AI旅居 #双城记
- 私信引导 → 官网报名表单

### 4.2 微信公众号

- 线路攻略长文（复用四城内容素材）
- AI 教学入门文章（深圳侧供稿）
- 用户故事访谈（真实感）

### 4.3 官网内容更新

- 用户故事（打码/化名）
- 组局成果展示（「上周末，8 个人在大理古城喝咖啡聊 AI」）
- 冷启动期可用「运营示范案例」代替真实 UGC

---

## 5. 活动运营（组局是核心验证）

### 5.1 线上活动（成本低、先跑）

- **AI 入门公开课**（深圳侧主讲，云南群直播/腾讯会议）
- **线上破冰局**（8 人一组，轮流介绍 + 交换意向）
- **需求墙周会**（每周五集中撮合）

### 5.2 线下活动（试点）

- 深圳：AI 交流局（顺带安利云南旅居）
- 昆明/大理：本地见面局（咖啡店/民宿，先小规模 10 人内）
- 之后：深圳小团 × 云南小团（对应「小团对小团」形式）

### 5.3 活动 SOP

1. 活动页/群公告发布（标题/时间/地点/人数/报名方式）
2. 报名表收集（复用表单）
3. 前 1 天提醒 + 到场签到
4. 活动后复盘 + 群内沉淀照片/感言

## 6. 用户运营

### 6.1 生命周期动作

| 阶段 | 动作 |
| --- | --- |
| 新访客 | 引导报名（表单）→ 进群 |
| 已报名 | 邀请完善资料卡（发模板/一对一辅导） |
| 已完善资料卡 | 邀请发需求 / 匹配推荐 |
| 已组局 | 回访、邀请写反馈、沉淀案例 |
| 沉睡用户 | 群内 @ + 活动召回 |

### 6.2 激励体系（V1 轻量）

- 完善资料卡 → 优先展示 + 社群曝光
- 主动撮合成功 → 「双城搭桥人」称号（无认证，纯荣誉）
- 优质案例 → 官网/小红书曝光

## 7. 信任与风控（无认证但有机制）

1. **平台规则**：官网「关于」页公示；禁止骚扰、诈骗、纯营销；
2. **举报机制**：群内找群主 / 官网提交举报（二期做站内）；
3. **黑名单**：运营维护，拉黑后移出所有群；
4. **安全提示**：线下见面公共场所、报备行程、涉及付费线下当面结清；
5. **付费服务原则**：平台只做展示撮合，不介入交易、不抽成（V1）；建议先小额试单。

## 10. 商业化试探（V1 就要埋的种子）

1. **付费带玩**：表单问「是否接受付费带玩」；试单小额（带玩 ¥100–300/天）；
2. **AI 课程**：深圳侧 AI 公开课积累内容，观察付费意愿；
3. **企业游学**：记录是否有企业/团队咨询（B 端线索收集）；
4. **会员社群**：等社区价值沉淀后再考虑，V1 不做；
5. 所有试探都只为验证，不急于收费 —— 先建立「交换」的心智。

## 11. 关键风险与预案

| 风险 | 预案 |
| --- | --- |
| 云南侧供给不足 | 加大本地 KOL 合作、先做「本地攻略内容」再引带玩人 |
| 群内沉寂 | 每周固定活动节奏、群主/轮值运营 |
| 付费服务纠纷 | 强调线下当面结算、平台免责条款、黑名单 |
| 品牌名未定 | 全站文案集中配置，随时可换 |
| 流量来了接不住 | 报名后 24h 内必须有人拉群（运营 SLA） |
